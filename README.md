🧠 Daily C++ Practice & Roadmap

This repository tracks my daily journey in mastering **C++**, focusing on modern language features, performance optimization, and strong programming fundamentals.
The core purpose is to build a disciplined daily coding habit, bridge foundational knowledge with practical implementation, and document continuous progress.

🎯 Goals

* Master C++ syntax and transition from **core fundamentals → OOP → modern C++ standards**.
* Understand low-level mechanics, memory management, and compiler behaviors.
* Maintain an active and consistent Git workflow.
* Build a solid foundation for competitive programming, systems development, and engineering projects.

📚 Learning Roadmap & Topics Covered
 Basic I/O & Variable Formatting (`std::cout`, `std::cin`)
 Arithmetic, Compound & Increment Operators (`++`, `--`, `+=`)
 Functions & Compiler Inlining (`inline` keyword, call overhead)
 Control Flow & Complex Conditions
 References & Memory Management
 Pointers & Dynamic Allocation
 Object-Oriented Programming (Classes, Encapsulation, Inheritance, Polymorphism)
 Modern C++ (Smart Pointers, STL Containers, Lambdas)
